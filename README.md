#Quiz App
A simple yet interactive Quiz App built using HTML, CSS, and JavaScript. This project is designed to help learners understand how different JavaScript concepts work in a practical application.

#Features
Interactive Quiz Interface: Users can answer multiple-choice questions.

Responsive Design: The app is fully responsive and works seamlessly on all screen sizes.

Score Calculation: Automatically calculates and displays the user's score at the end of the quiz.

Dynamic Question Rendering: Questions and options are dynamically rendered using JavaScript.

User Feedback: Provides immediate feedback on the correctness of answers.

#Technologies Used
HTML: For structuring the quiz interface.

CSS: For styling and making the app responsive.

JavaScript: For handling quiz logic, dynamic rendering, and score calculation.

JavaScript Concepts Demonstrated
DOM Manipulation: Dynamically updating the quiz questions and options.

Event Handling: Handling user interactions like button clicks and answer selection.

Arrays and Objects: Storing and managing quiz questions and answers.

Conditional Logic: Checking correct answers and calculating scores.

Functions: Modularizing code for better readability and reusability.
